# marvell-dash

Personal start-page dashboard in the same black/white ASCII + dither style as marvellkern.online.

Time + world clocks, sun path, Semarang weather (Open-Meteo), Indonesian and world news (RSS via rss2json), USD/SGD/EUR → IDR rates (Frankfurter), quick links and notes.

One static file: `index.html`. Edit the `CONFIG` block at the top of the `<script>` to change links, feeds, cities or currencies.

Shortcuts: `R` refresh, `N` notes, `1`–`9` quick links.
